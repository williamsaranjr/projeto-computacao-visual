O que é dithering?

Dithering simula tons intermediários por meio de padrões de pontos. Mesmo usando poucas tonalidades reais, o olho humano percebe texturas e transições suaves.

Bayer aplica uma matriz de limiares ordenados. Floyd–Steinberg distribui o erro para quatro vizinhos. Jarvis–Judice–Ninke espalha o erro por uma vizinhança maior, produzindo outra textura.
