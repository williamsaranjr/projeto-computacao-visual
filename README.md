### Execução
1. Extrair os arquivos do ZIP.
2. Abrir index.html com Chrome, Firefox ou Edge.
3. Clicar em "Usar imagem de exemplo" ou selecionar uma imagem.
4. Escolher Bayer, Floyd-Steinberg ou Jarvis e ajustar as opções.
5. Clicar em "Baixar imagem processada" para salvar o PNG.
6. Não é preciso compilar, instalar pacotes ou configurar servidor.
